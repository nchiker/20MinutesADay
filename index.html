Backup & Settings

Backup your data

Everything is stored only on this device. Export a backup file regularly, especially before switching phones or clearing browser data.

Restore from backup

Restoring will overwrite the app's current progress with what's in the backup file.

Reset progress

Wipes all logged sets, levels, and cardio history on this device. Cannot be undone unless you have a backup.

How leveling works

Each exercise has 6 progressive levels. Hit the full target on every set for an exercise, on 3 different days, and it'll be flagged ready to level up — bump it whenever you like from the exercise screen.
